# SDGallery

**System Design Gallery** — free, open, beginner-friendly system design education with visuals and plain-language case studies.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test
npm run build
```

## Content

| Path | Purpose |
|------|---------|
| `content/companies/` | Company directory entries |
| `content/patterns/` | Pattern / concept pages |
| `content/case-studies/` | Full learning case studies |
| `content/contributors.json` | About page contributors |

See [CONTRIBUTING.md](./CONTRIBUTING.md) to add content via pull request.
